# Topic opportunities

Read and obey `../seo-contract/SKILL.md` before starting. No push, merge, publication or scheduling is allowed.

Adapted from the described money-keywords workflow, retaining informational topics valuable to a personal site. This is analysis only.

1. Inventory existing URLs, the author's stated goals and supplied original material. Identify reader questions the author can answer from real experience. Do not manufacture expertise or exclude informational intent merely because it is not transactional.
2. Use optional supplied Search Console data, public search-result observations, Suggest or Trends only within authorized read-only access. Planner data is accepted as a supplied export; do not create an advertising account. Record source, date, language/location and collection method. Avoid automated search scraping and private names in external queries.
3. Group related questions by intent and compare each to existing content. Suggest an update before a duplicate page where appropriate. Distinguish observed query–URL results from market estimates and qualitative demand hypotheses. Never infer top-ten placement from impressions alone.
4. Return at most five candidates with audience, question, original material, intent, existing URL or proposed target, update/new/no-change recommendation, evidence, missing inputs and confidence. Include `volume: null` unless measured; measured volume needs provider, period and market. Use priority justified by reader value, author material and effort, not invented SEO scores.
5. Reject location permutations, reciprocal rankings, bought links, forced best/year titles and bulk page production. Pass a selected candidate to page-brief rather than writing a page.

End **opportunities ready for owner review; site diff: none**. In no-data mode, explicitly label the list as content hypotheses, with no measured demand or ranking claim.
